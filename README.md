## Build
pretty simple build

if any issues consult makefile
### Requirements
- CMake
- GCC
- Ninja

### Building
1. Run "make" or "make all" in terminal
2. Places binary in ./build/bin

can also be made without make via: 
- cmake -S . -B build/cmake -G Ninja

### Cleanup
make clean

or just delete build
